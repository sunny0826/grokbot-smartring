# 轻点唤出控件

2026-10-17，用户要求说话按钮及 Wi-Fi／电量默认隐藏，轻点唤出，10 秒无触摸后隐藏。
固件版本 `0.9.1-tap-controls`。

主页背景和角色画布共同接收轻点：松手后唤出，滑动和长按不唤出。第一次点击原本
隐藏的按钮位置不会开始录音或打开配网。顶部栏和空闲说话按钮使用同一可见状态，
以 LVGL 输入活动时间判断 10 秒空闲，100ms 刷新；动画和网络状态更新不会延长时间。
持续按住录音不会隐藏录音按钮；配网和回复的内容层不受该计时影响。未读入口保持原行为。

已验证：

- 生产 LVGL Wi-Fi/语音联合界面：默认隐藏、隐藏位置首击仅唤出、10 秒空闲隐藏、
  期限内再次触摸重新计时、滑动和长按不唤出、配网二维码页面空闲超过 10 秒仍可操作。
- 生产 LVGL 语音界面：隐藏状态首击不录音、第二次按住正常、持有超过 10 秒不隐藏，
  原松开发送、滑出取消、快速点按、回复分页和已读行为回归通过。
- 隐藏／显示／超时截图目视核对；背景是 host 测试底板，不冒充实物角色画面。
- IDF 5.5.3 构建与分区容量检查、`git diff --check` 通过。
- 烧录前保存了私有 Flash 备份，并校验旧应用与 0.9.0 最终 SHA256 一致。
- 仅应用区烧录并校验成功；USB 读回 `0.9.1-tap-controls`、`link: wifi`、WSS 无连接错误，语音 Idle。
