# 点击头像读消息，精简进行中文字

2026-10-17，固件 `0.12.2-avatar-inbox`。

后续更新：[0.12.3 放大读取回复动画](reply-animation.md)。

首页移除“未读回复”按钮。有未读消息时，轻点带蓝点的动画头像即可进入消息；点击区域跟随真实绘制位置和大小，缩成小点时仍保留至少 44 px 的基础触摸尺寸。短按只打开一次，长按、拖动、消息状态变化后松开、配网遮挡期间松开均不打开消息。标记已读仍需要明确操作。

进行中只保留一行状态文字：正在上传、等待处理、正在转写、等待接单、正在处理、正在读取回复或正在标记已读。可离开的阶段保留“返回”；录音、错误、需核对及阅读界面的必要提示保留。

[查看三皮肤实际渲染预览](voice-character-fusion.html)。这些是注入测试状态的真实 LVGL 画面，不是实机录像，预览图片本身不处理设备操作。

## 实现与验证

`CharacterPresenter` 利用已有 canvas/screen 的输入事件，记录真实头像中心和半径，没有新增每帧移动的透明按钮。回调先于原主页手势注册：按下允许原手势初始化；头像短按消费后续释放/点击；超过与原手势一致的任一轴 40 px 阈值后继续交给主页。松开时再次校验 Idle、未读、generation 和遮挡状态。两种表面删除/重建时清理指针，析构和重新 attach 移除自身回调。

`voice_ui` 删除旧 inbox 控件及其状态，只隐藏进行中的说明 label，进入需要说明的阶段时重新显示。没有改变录音、上传、自动回复或手动已读的服务逻辑。

- 真实 LVGL 语音烟测通过：三皮肤 × screen/canvas 两种事件入口；短按恰一次 Open，长按/滑动/过期 generation/清除未读/配网遮挡不 Open；后置事件观察器确认短按释放被消费、拖动继续发送 PRESSING/RELEASED 给后续处理。
- 实际 `draw_home` 移动头像后，旧位置点击无效、新位置点击有效；小头像的扩大点击区域有效。七个进行中阶段分别只有一个标题，或标题加“返回”两个可见 label。
- 原语音交互、删除重建、头像叠加、真实 Wi-Fi UI 回归通过。主机测试没有执行主循环的实体换肤/摇晃，手势兼容结论还包括对原回调代码与注册顺序的检查。
- 三皮肤首页、等待及思考截图已目检，无未读按钮，进行中无说明段落。
- 生产 OFF 构建通过，应用 `0x1c47f0` 字节，分区剩余 12%。独立同模型只读审查无阻断。
- 烧录哈希校验成功；55 秒观察的 11 次设备回读均为 `0.12.2-avatar-inbox`，Wi-Fi 重连，未记录到 Draw bitmap failed / TE wait timeout。

证据与源文件哈希保存在 [avatar-inbox-evidence](avatar-inbox-evidence/)。实体触摸、移动中点击和录音到回复的观感仍待实际使用确认。本轮没有改云端任务、服务、模型或既有主页动作。
