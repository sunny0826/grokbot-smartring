## 使用及限制

Wi-Fi 图标 → 手机配网 → 扫第一张码加入 MyBot 临时热点 → 下一步打开
`http://192.168.4.1` → 选网并输入密码。两张码都有文字备用，圆屏键盘保留。
热点最多 5 分钟，成功约 30 秒后关闭。试连/重扫可能短断；网页仅自动重试 GET。
本轮没有自动弹出门户。要给操作手机自己的热点配网，应使用另一台手机或圆屏键盘。

HTTP 只允许临时 AP 地址及同源会话访问；底层监听仍是 wildcard，不能称为 socket 原生
绑定 AP。目标网段与 `192.168.4.0/24` 重叠时关闭网页，以圆屏结果为准。
`httpd_stop` 仍依赖 IDF 控制消息和任务退出，不能将 socket 的 3 秒期限写成 stop 的严格上界。
此记录仅陈述已执行的验证，不将代码发布视为手机实物验收。
