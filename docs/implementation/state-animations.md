# 对接原有状态动画

2026-10-17，固件 `0.12.1-state-animations`。用户指出新消息、思考中、进行中已有对应动画，要求适配。

后续 `0.12.2` 已[改为点击头像进入未读消息，并精简进行中文字](avatar-inbox.md)；当前预览链接展示最新版本。

[查看三种角色预览](voice-character-fusion.html)。使用实际固件绘图和 LVGL 界面，流程状态与音量由测试注入；不是实机录像。

| 实际状态 | 使用的既有动画 |
| --- | --- |
| 收到回复 | `Notify`：蓝点弹出；前台仍立即自动打开回复 |
| 首页有未读回复 | 原 `Notify` 蓝点叠加在当前角色上；不覆盖首页动作，也不自动打开阅读页 |
| Grok 已领取、正在处理 | `Thinking`：角色缩成中间点，与左右两点依次脉动 |
| 上传、已保存、转写、等待接单、加载页面、标记已读中 | `Orbit`：环绕线持续旋转，直到阶段改变 |
| 录音 | 保留音量驱动的伸缩反馈 |
| 错误、需核对、待发送、取消 | 保持静止，显示对应说明和操作 |

本轮删除 0.12.0 中自定义的处理脉冲和等待呼吸，直接复用 `poseFor`。三种皮肤共用原动画，Thinking 时中间点保留各自的身体颜色。

原 Orbit 会在约 3.6 秒后退场。新增 `PosePlayback::Continuous` 只供持续任务使用，保留环绕和注视；默认 `OneShot` 保持原轮播及手动动画行为。没有复制一套动画常量，也没有把每次状态查询当作动画重播。

首页未读标识读取同帧 VoiceSnapshot，只在未读从无到有时启动蓝点弹出。generation 更新和菜单遮挡不重启。显示时复制当前姿态，只叠加通知参数，不修改主循环的姿态、物理、轮播或远程动画。标记已读后移除这层标识；原首页演示轮播仍可独立播放 Notify。

## 验证

- 三皮肤 1,920 帧语音角色逐像素参考比较通过；确认原 Thinking 的三点形态在动、全部进行中阶段 30 秒后仍有环绕动画、原 OneShot 仍按时退场。
- 原渲染 2,620 帧及真实 LVGL 合成 180 帧回归通过。
- 真实 LVGL 语音界面：未读蓝点出现、generation 不重播、遮挡不绘制/恢复不重播、清除未读标识通过。
- 三皮肤 × Thinking / Dizzy / Orbit 的首页绘图，未读前后像素差仅在蓝点邻域；传入的姿态没有被修改。原按住/松开/滑出取消、过期点击、自动打开、阅读、删除重建测试通过。
- Wi-Fi 菜单与 operation Closed 两条恢复路径、旧配网交互回归通过。
- 目检三皮肤环绕、思考、回复和未读截图；预览脚本语法检查通过。测试状态不能证明麦克风、云端耗时或物理屏幕观感。
- ESP-IDF 生产构建通过，benchmark OFF，应用 `0x1c46f0` 字节，分区剩余 12%。
- 烧录哈希校验成功；55 秒观察的 11 次状态回读均为 `0.12.1-state-animations`，Wi-Fi 重连，未记录到 Draw bitmap failed / TE wait timeout。实体录音到回复的画面观感仍待实际使用确认。
- 同模型独立只读审查无阻断；2 行不再准确的退场说明注释已删除。审阅者读回最终测试日志，没有独立操作设备。

证据保存在 [state-animation-evidence](state-animation-evidence/)。沿用[上一版的复跑命令](voice-character-fusion.md#复跑)。本轮不修改语音服务、Bot 指令或模型，也不声称云端提速或达到 30 fps。
