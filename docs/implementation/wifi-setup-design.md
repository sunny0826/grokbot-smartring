# 圆屏 Wi-Fi 配网实现设计

2026-10-17。用户要求直接在圆屏搜索、选网、输入密码并连接，随后明确要求实施。
基线为183a400及当前未提交的0.7.0-remote/语音功能。实施和验证状态另记，未授权提交或推送。

## 选型

按 architect/arena 流程完成两个独立候选及独立评判，三者使用宿主继承模型，
不声称跨模型实验；协调者已完整阅读两份候选和评判，并核对关键调用。
选择A：现有gadget任务拥有Wi-Fi驱动和换网事务，语音任务在自身安全边界确认暂停。
UI只发命令、读快照。B的独立Wi-Fi任务仍需等gadget同步连接返回，不能消除等待，
却多出第二套暂停协议和任务栈，本轮不采用。

吸收B的原子操作门，以及事件溢出、停止屏障、独立取消标志的约束。
设置页立即可见；准备阶段等当前网络调用结束，未取得语音暂停确认不切网。
不将每次HTTP I/O的15秒超时冒充整个请求的总时限。准备期间可以撤销。

## 行为与持久状态

点顶部Wi-Fi图标进入扫描列表，选择网络，在分页大键盘输入ASCII密码。
关联目标网络且获得IP后才保存；失败或取消恢复旧网络。设置过程不重启、不释放
未上传PCM、不清语音journal，不自动重发上传失败的录音。

驱动配置明确使用RAM。SSID和密码以单个版本化NVS记录保存，旧键只在新记录缺失时
作为兼容读取来源；所有USB网络写入口同步使用同一存储格式。保留token、CA、
remote_host等其他配置。取消在Saving前优先，Saving是短暂不可取消提交点。

支持扫描到的2.4GHz开放/WPA2个人网络；不新增企业认证、隐藏SSID手工录入、
网页认证登录、多网络库或手机配网。中文SSID使用已有LVGL常用汉字字体，
对无法显示的字节提供可区分的显示方式，实际连接始终使用原SSID字节。

- UI ownership：wifi_setup_ui与键盘实现、status_bar.cpp/.h、main.cpp、对应真实LVGL主机UI测试。不得修改网络/voice实现、共享wifi_setup.h或生成字体。

两部分依赖先固定的公共命令/快照头；执行者不修改他人文件，有边界需求反馈协调者。
沿用共享当前工作区以保留大量已部署但未提交的基线；按上述不重叠文件所有权写入，
仅协调者运行共享build目录和操作设备。独立测试各自使用临时输出目录。
