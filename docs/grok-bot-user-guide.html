日常使用，做这三步

  1. 给设备供电，让 Mac 保持唤醒

    沿用当前供电方式。Mac 上的网关和 Cloudflare 隧道都需要运行；它们目前没有配置开机自启。

  2. 看看顶部 Wi-Fi 标志

    轻点主页可显示 Wi-Fi 和电量，10 秒无触摸后隐藏。绿色表示连上路由器。绿色本身不能证明 Grok 连接器和网关都正常。

  3. 打开已连接设备工具的 Grok Bot 对话

    先发下面这句话。要测试动画，先把设备平放在桌上。

请使用 grok-gadgets 工具列出设备，找到真实的 SmartRing-Plus 圆屏，忽略模拟灯。读取它的在线状态和电量，然后让它播放 happy 动画。请实际调用工具，并告诉我命令是否执行成功。

看到工具返回 executed，再看屏幕是否动了。明显倾斜会打断开心、思考等轮播动画，恢复重力动作；动画也不会一直停留在同一表情。

和 Grok 的边界

这些动作可以独立运行，不依赖 Grok。

事件上传到网关后，Grok 可以调用工具读取。目前没有“点屏幕就自动唤醒 Grok”的常驻触发器。

语音信箱支持短文字回复回屏；尚未实现双向语音聊天或播放音乐。

按住说话，松开发送

  1. 按住屏幕按钮

    先轻点主页，再按住底部「按住说话」，看到「正在录音」后再说话。控件在 10 秒无触摸后自动隐藏。

  2. 松开发送

    录音上传到 Mac，在本地转成文字。不想发送时，将手指滑出按钮即可取消。

  3. 让 Bot 处理

    看到「等待 Grok 领取」后，在原 Bot 说「处理圆屏语音」。回复到达后可在圆屏打开、翻页和标记已读。

最长录音 30 秒，松手才发送。快速点按不会发送。请使用屏幕入口，实体按钮长按可能关机。

语音信箱复用现有 MCP；录音不会自动唤醒 Bot。原局域网触摸录音与真实 Grok 回复已获用户验收；远程热点链路另行验证。详见语音使用与配置。

遇到问题，按现象找

圆屏可以带出门吗？

可以。远程域名设置好后，固件 0.9.0 可点 Wi-Fi 图标，用手机网页或圆屏输入密码，连接其他 2.4 GHz Wi-Fi。若要连接操作手机自己的热点，请用另一台手机打开网页，或使用圆屏输入。家中 Mac 需要持续联网、保持唤醒。

默认 LAN 模式仍要求同一局域网。切换方法见跨网使用，不需要重新设置 Grok 连接器。

Grok 找不到圆屏，或只有一个模拟灯

让 Grok 先调用 gadgets_list_devices，选择具有 character.set 能力的真实 SmartRing-Plus，忽略模拟设备。若列表中没有圆屏，检查供电、Wi-Fi、Mac 网关。

Wi-Fi 是绿的，Grok 却控制不了

Wi-Fi 绿灯只表示连上路由器。确认 Mac 没有睡眠，网关和隧道仍在运行，然后让 Grok 再读取一次设备状态。401 通常需要检查授权；隧道出现 502 时先检查 Mac 和网关。

Grok 说成功了，动画却看不出来

把设备平放后再试。明显倾斜会切回重力动作。要求 Grok 报告工具返回的执行状态；若结果仍为 pending，让它继续查询 gadgets_command_status，不要直接把“已发送”当作“已执行”。

屏幕黑了，但设备还在线

先说：“把圆屏背光调到 60%。”亮度设为 0% 会关闭背光。

Mac 重启后不能用了

目前网关和隧道没有配置开机自启，需要重新启动。Wi-Fi 模式的网关必须带 --lan-listen GATEWAY_LAN_IP:8767；仅启动 USB 桥接不能恢复无线连接。

地址发生变化时，还要检查 LAN 证书和设备保存的网关地址。远程模式还需启动设备 relay 和语音服务。具体部署参数见跨网使用及维护指南。

首次连接，或需要重新授权 Grok Bot

已经能调用设备工具时，跳过这里。否则在 Mac 端 Grok Bot 的一对一对话中发送以下内容，把示例域名替换为你已有的隧道域名：

请添加一个自定义 MCP 服务器，名称 grok-gadgets，类型 Remote HTTPS，地址 https://gadget.example.com/mcp，使用 OAuth 登录，不手动填写请求头或令牌。

  1. 确认 Grok 的添加服务器卡片，选择 Authorize / Continue。
  2. 在打开的授权页查看本次授权码。
  3. 在 Mac 的项目目录执行下面的命令，用页面上的码替换 CODE。
env -u ALL_PROXY -u all_proxy -u HTTP_PROXY -u http_proxy \
  -u HTTPS_PROXY -u https_proxy \
  .venv-grok/bin/grok-gadgets-gateway oauth approve CODE

完成后让 Grok 列出设备。只批准自己刚打开的页面上的授权码。流程依据网关项目接入说明；无需把密码或令牌发进聊天。

暂时停止 Grok 远程控制

在项目目录执行；设备上的本机动画仍可运行：

.venv-grok/bin/grok-gadgets-gateway remote off

恢复时将 off 改为 on。

本次核对：真实设备在线，状态为 link: wifi，网关提供四项设备命令。此前无线 MCP 命令返回 executed。本说明书编写时仅查询状态，没有重新执行 Grok App 端测试，也没有完成独立电源测试。
